v1.0 — Backend PostgreSQL

STOKVA

Gestion complète des dépôts de stockage : réceptions, expéditions, pont-bascule, transferts inter-dépôts et reporting réglementaire.

powered by NETPROCESS

Une refonte multi-utilisateurs

STOKVA passe d'une application mono-poste (localStorage) à une vraie solution client-serveur PostgreSQL, conçue pour l'usage simultané sur plusieurs sites.

⚖

Pont-bascule série réelle

Lecture RS232/USB en continu (Toledo, Mettler, génériques). Mode 1 ou 2 passes, simulation intégrée pour tester sans matériel.

📊

Registre G0 + exports

Conforme norme marocaine EN 07-O04. Export Excel et PDF en un clic, filtrage par mois et par dépôt.

⚡

Temps réel WebSocket

Toutes les actions (réceptions, expéditions, pesées) diffusées instantanément à tous les postes connectés.

🔐

API REST + JWT

Documentation Swagger, authentification par tokens, 4 rôles RBAC (admin / responsable / opérateur / consultation).

↔

Transferts inter-dépôts

Workflow envoi → en transit → réception. Tolère les réceptions partielles, tracé complet des mouvements.

🇲🇦

Conformité Maroc

ICE, RC, IF, CNSS, Patente sur la société et les partenaires. Devise MAD, numérotation séquentielle annuelle.

Déploiement adaptatif

Trois modes prêts à l'emploi, scripts d'installation fournis.

🐧

VPS Linux

install-vps.sh — installe Node, PostgreSQL, crée un service systemd, configure nginx.

🪟

Windows

install-windows.bat — détecte les prérequis, crée la base, installe en service Windows via NSSM.

🐳

Docker

install-docker.sh — orchestre Postgres, backend et frontend nginx en quelques secondes.
